# Правила проекта SOVELIRA

## Продукт
Сайт бренда шуб SOVELIRA с записью на примерку в шоурум. Подробно — PRODUCT.md, визуальные правила — DESIGN.md, решения — DECISIONS.md.

## Стек
Next.js 16 (App Router), React 19, TypeScript, Tailwind 4, shadcn/ui, Vitest, Playwright. Node 24 (см. .nvmrc и package.json). Точные версии — в package-lock.json.

## Команды
Windows: если `npm` блокируется, писать `npm.cmd`.
- Установка: `npm ci`
- Запуск: `npm run dev` → http://localhost:3000
- Проверки: `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`

## Рабочий цикл
1. Прочитай PRODUCT.md, DESIGN.md, DECISIONS.md и спецификацию задачи в docs/specs.
2. Предложи план: какие файлы изменишь, какие команды запустишь, как проверим.
3. До моего подтверждения плана ничего не меняй.
4. После работы покажи список изменённых файлов, diff и результаты проверок.

## Коммиты
Коммиты делает только человек. Формат: `feat: …`, `fix: …`, `docs: …`, `revert: …`; во второй строке — «Зачем: …».

## Запреты
- Не устанавливать и не удалять пакеты без моего согласования (видно в package.json и package-lock.json).
- Не создавать и не менять файлы .env*, не выводить ключи и пароли (видно в git status).
- Не менять схему базы без миграции в supabase/migrations.
- Не писать цвета, размеры шрифта и радиусы прямо в компонентах — только через токены в app/globals.css (видно в diff: hex-цвета и px-значения в className).
- Не добавлять оплату, корзину и доставку — их нет в PRODUCT.md (видно по новым страницам и маршрутам).
- Не показывать в интерфейсе имена и телефоны других клиенток (видно в компонентах «Мои примерки» и каталоге).
