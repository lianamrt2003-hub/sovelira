# Фича: каталог шуб на моках

Что: страница «Каталог» со списком шуб на моковых данных.
Для кого: клиентка, которая выбирает шубу для примерки.
Сценарий: открыть главную страницу → увидеть каталог шуб.
Дано: в моках 6 шуб. Когда: открыта главная страница. Тогда: видны 6 карточек; у каждой название, цена, цвет и доступные размеры; у шубы без размеров в наличии подпись «Нет в наличии».
Чего не делать: не подключать Supabase, не ставить пакеты, не трогать .env, не делать корзину и оплату, не менять общий layout.
